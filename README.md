# PotaninaJulia
# Моё лето 2026

Учебный проект — адаптивный сайт о событиях моего лета 2026 года.

На сайте представлены:
- светлая и тёмная версии;
- истории за июнь, июль и август;
- фотогалерея со слайдерами;
- адаптивная версия для мобильных устройств;
- плавная навигация по месяцам.
